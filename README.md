# Pagina-web — Victorius y la Ciencia (Team Credits)

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

A static HTML/CSS team credits page (*"Créditos del Equipo"*) created for **Victorius y la Ciencia**, a student science magazine project from *Escuela Secundaria Oficial No. 0940 Octavio Paz*.

## Technologies Used

- **HTML5** — Semantic structure for contributor credits and closing inscription
- **CSS3** — Flexbox layout, circular avatar styling, continuous keyframe scroll animation (`@keyframes scroll`), and responsive media queries

## Key Features

- **Animated Credits Roll**: Continuous `60s linear infinite` vertical scroll animation on a dark cinema-credits theme.
- **Section Attribution**: Credits each team member and their corresponding magazine section with circular profile image slots.
- **Responsive Layout**: Automatically adapts from stacked mobile layout to horizontal row cards at `min-width: 600px`.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ReySombras12/Pagina-web.git
   ```
2. Open `PaginaWeb.HTML` in any modern web browser.
   *(Note: Profile images `imagen1.jpg`–`imagen5.jpg` referenced by the HTML are stored in the companion repository [`ReySombras12.github.io`](https://github.com/ReySombras12/ReySombras12.github.io).)*
